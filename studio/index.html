A simple editor for portfolio videos, production credits and contact information. No Cursor required.

Publishing & privacy: This page does not request or store GitHub passwords or tokens. You can prepare edits here, preview them, then publish via your own GitHub account. Changes only become public after the JSON file is committed and the updated website is deployed. This page itself is not a password-protected CMS.

PUBLIC CONTACT DETAILS

Only add your personal email once you are comfortable publishing it. Agency contact details are currently verified.

VIDEO LIBRARY

For YouTube, paste a normal youtube.com/watch?v=... URL. Category assigns the video to Film, Improv, Voice, Monologues or the General YouTube library. Only mark a video as visible when it is cleared for public use.

FEATURED PRODUCTIONS

The Video ID field links a production to a video from the library. Example: enter the video ID for the Muzi scene once its actual recording is available.

How to publish without Cursor:
  1. Click Copy JSON above.
  2. Open site-content.json in GitHub and replace its contents with the copied JSON.
  3. Select Commit changes. The GitHub file will hold your updated content.
  4. The website must then be redeployed to Vercel until automatic GitHub deployment is connected. This editor does not secretly publish changes.
